# Visual Grammar

Why each shot in the reference films is there, how it moves, and how to reuse the thinking without copying the look.

Every observation below came from reading consecutive frames around each key moment, not from a one-per-second contact sheet. That's where the real craft hides: a contact sheet shows a ball in the sky, but frame by frame it's a coin with the logo on it, flying into a phone.

## 2. The twelve principles

Each one is a way of thinking, not a look. The "translate" line is how to use it without copying anyone.

1. **Hero object.** One physical thing that *is* the product's mechanic (Cero's coin = flip for cashback; Predictstreet's pack = collect and win). *Translate:* ask "if our product's core action were an object you could hold, what is it?" A transfer could be a paper plane. A savings goal could be a jar.

2. **Object carry.** The hero object travels between worlds and across cuts: sky to phone, pack to ticket to number. The eye follows the object, so the film feels continuous. *Translate:* plan every major transition as "what object carries the eye across this cut?"

3. **Object as wipe.** The object fills the frame for a few frames and that *is* the cut (pack wipes type; ball fills lens). *Translate:* any hero object can be a wipe if it moves toward camera or across frame fast enough to cover it.

4. **Anchor swap.** Keep one thing fixed in screen position and swap the world around it (the fan, the hand and card, the logo lockup). It says "same product, everywhere." *Translate:* for any "anywhere / anytime / anyone" benefit, find the constant (a hand, a card, a phone, a line of text) and swap the world.

5. **Shape rhyme.** One shape repeats in every graphic (Cero: circles everywhere; Plasma: the ring mark). Unrelated shots start to feel like one system. *Translate:* derive the shape from the logo or the hero object, then use it for masks, gauges, buttons and transitions.

6. **Bookend.** Open and close on the same object or mark. The last shot answers the first. *Translate:* the first two seconds and the end card should share one visual element.

7. **Rolling values.** Numbers never just appear; they roll, count or tick (odometer salary, currency slot, stat counters, chart counter). Moving numbers feel alive and earned. *Translate:* every number on screen moves. Use the slot-machine roll for categories too, not only digits.

8. **Level-up inversion.** When a threshold is crossed, the world changes: palette flips, background inverts, sunburst appears. *Translate:* pick the one milestone in your story and change the whole frame at that moment, not just the number.

9. **Depth sandwich.** Put type *between* objects: words behind the pack, card in front; pack rising out of the phone. Flat graphics gain depth. *Translate:* in HyperFrames, give type, object and UI their own z-layers and animate them at different speeds.

10. **Overload, then void.** Accelerate (shorter shots, glitch, blown-out white), then cut to black and near silence. The emptiness lands the next line. *Translate:* once per film, right before the turn. The quiet school skips the overload and keeps only the void.

11. **UI in the world.** Product UI is timed to real human action: the payment confirms as he walks past, the toast appears as she checks her phone. *Translate:* never show a UI screen alone if you can show it reacting to a person.

12. **Visual pun.** Background footage is chosen because it means something about what's on top (Bridge on a bridge, Aave on a wake). *Translate:* for every B-roll shot, write down why *this* place, before shooting or generating it.

## 3. Tying it into one film: the thread method

Beautiful films feel like one continuous thought. That comes from threads: things that persist across cuts.

1. **Pick the hero object.** It's the product's mechanic made physical. It opens the film and closes it (bookend).
2. **Pick the shape.** Usually the hero object's outline or the logo. Every mask, gauge, button and transition uses it.
3. **Pick one anchor** for the breadth section ("everywhere", "every currency").
4. **Pick the one milestone** where the world inverts.
5. **Write the transition chain.** For each cut, name what carries the eye:

   | Carrier | Use for |
   |---|---|
   | Object carry | Moving between real world and UI |
   | Object as wipe | Leaving a scene with energy |
   | Anchor swap | Breadth: places, currencies, people |
   | Shape match | Graphic to graphic (circle to circle) |
   | Color wipe | Section changes |
   | Word per beat | Building a key line |
   | Hard cut on beat | Montage rhythm |
   | Void | Once, before the turn |

   Rule: the key sequence has no "dead" cuts. Plain hard cuts are fine in montages, where rhythm is the carrier.
6. **Make every number move**, and make one number cross the milestone.
7. **End on the hero object** turning into the logo.

## 4. Worked example (fictional)

A made-up product to show the method end to end: **loop.**, a card that rounds up every purchase into savings.

- **Truth:** loop. turns spare change you never notice into a savings pile you can watch grow.
- **Device:** make it a game, plus receipts.
- **Hero object:** a coin. Spare change is literally coins.
- **Shape:** the circle (coin, ring gauge, masks).
- **Anchor:** the card in a hand, locked on screen while cities swap.
- **Milestone:** the savings pile crosses $1,000 and the frame inverts from white to brand color.

| Time | What we see | Carrier into next shot |
|---|---|---|
| 0.0-1.5 | A coin spins up off a café table in slow motion, catching light | Object carry: coin flies at lens |
| 1.5-3.0 | Coin lands in a phone UI: "+$0.40 rounded up" | Hard cut on beat |
| 3.0-6.5 | Hand and card locked center; tap, whip, tap, whip: Lisbon bakery, Tokyo vending machine, NYC bodega. Each tap drops a "+$0.xx" coin chip | Anchor swap |
| 6.5-8.0 | Every coin chip flies into one ring gauge | Shape match (coins to ring) |
| 8.0-11.0 | Ring fills while "Saved" rolls $412 to $999 | Rolling value |
| 11.0-12.0 | Crosses $1,000: white flips to brand color, sunburst | Level-up inversion |
| 12.0-13.0 | Near silence, black. "Spare change." | Void |
| 13.0-14.5 | "Isn't spare." Music returns | Word per beat |
| 14.5-19.0 | The coin spins once more and resolves into the loop. mark | Bookend |

Nothing in this copies a reference. It borrows the thinking: hero object (Cero), anchor swap (Plasma), rolling values (everyone), level-up inversion (Plasma Year One), void (Motoswap, Plasma).

## 5. Timing cheat sheet

Approximate, read off consecutive frames.

| Move | Timing |
|---|---|
| Object carry, real world to UI (Cero coin) | about 0.6s from sky to phone |
| Word-per-beat build (JOIN / THE / GAME) | one word per beat, about 0.35s at 184 BPM |
| Serif type build, word by word (Cero) | about 0.3s per word, soft fade with slight blur |
| Word slot roll (Plasma currencies) | about 0.6s per value, the roll itself about 0.15s |
| Anchor swap whip (Plasma FX) | about 0.35s of motion blur between scenes |
| Logo storm (Year One) | 10 frames per partner, 0.417s at 23.976fps |
| End line push-in (Motoswap) | slow scale-up over 4s while words add |
| End card hold | 4 to 6s |
| Void before the turn | 1.5 to 3s |
